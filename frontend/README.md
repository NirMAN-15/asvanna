# 🖥️ ASVANNA Web Admin & Divisional Officer Dashboard

The administrative web portal for Divisional Officers (Department of Agrarian Development) and Super Administrators.

## 🌟 Key Features

- **Regional Cultivation Monitoring**: Visual tracking of planting clusters across Bandarawela.
- **Predictive Risk & CROPIX Saturation Matrix**: Real-time evaluation of crop supply against national/regional quotas.
- **Proxy Data Entry**: Officer proxy form for offline farmers without smartphones to ensure total digital inclusivity.
- **Broadcast Warning Dispatch**: Multi-lingual notification broadcast with instant FCM push and SMS fallback.
- **Trilingual Localization**: Complete support for English (`en`), Sinhala (`si`), and Tamil (`ta`).

## 🛠️ Tech Stack

- **Framework**: React.js (Vite)
- **Styling**: TailwindCSS
- **Icons**: Lucide-React
- **State & Context**: React Context API
- **HTTP Client**: Axios

## 🏃 Local Setup

```bash
# 1. Install dependencies
npm install

# 2. Copy environment file
cp .env.example .env

# 3. Start development server
npm run dev
```
